# 🎡 Presentation Lottery System

A simple Python-based lottery system designed to randomly assign teams to presentation order in a classroom setting.

## 🚀 Features

- Generates teams automatically based on user input
- Random selection of teams
- Ordered assignment of presentation positions
- Results stored in a dictionary for easy display
- Clean separation between logic and helpers

## 🧠 How it works

1. User enters number of teams
2. System generates teams (Equipo 1, Equipo 2, etc.)
3. Teams are randomly selected one by one
4. Each team is assigned a position in reverse order
5. Final remaining structure represents the presentation order
